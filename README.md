# BARD plugin marketplace

Claude plugin marketplace for **BARD — Bonhams Auction Research Database**.

## Install

```
/plugin marketplace add sgfrith67/bard-marketplace
/plugin install bard@bard-marketplace
```

## Plugins

| Plugin | Version | Skills |
|---|---|---|
| [`bard`](plugins/bard) | 0.4.3 | `comparable-sales`, `lot-estimate`, `auction-query`, `bard-home` |

See [plugins/bard/README.md](plugins/bard/README.md) for setup (Supabase access token, connector) and usage.
